# Transaction Overview & Capitalization

> Fictional investor-side legal work sample; not legal advice.

## Transaction snapshot

Project Aurora / 星澜智能科技有限公司（虚构）是一家境内AI软件有限责任公司。远山成长基金拟通过增资投入人民币3,000万元，投前估值人民币2.2亿元，全部完成后投后估值人民币2.5亿元，投资方持股12%。拟于2030年12月31日前完成合格A股IPO。

## Assumptions and transaction mechanics

为使两期付款和股权比例可核算，本次样本假定：首期2,000万元、第二期1,000万元分别对应两次新增注册资本/工商变更；无其他期间融资、期权池调整或股权转让；投资估值与认购股权按照统一的2.2亿元投前基准测算。实际交易中需在正式协议中约定两次交割的股权取得时点、登记期限、第二期不付款时的后果及权利计算。

## Cap table

投前：创始人65.9091%；其他股东34.0909%；投资方0%。第一期后：创始人60.4167%；其他股东31.2500%；投资方8.3333%。第二期后：创始人58.0000%；其他股东30.0000%；投资方12.0000%。各期比例按投前220m、第一期后240m、第二期后250m推导；四舍五入差异以交易文件约定为准。

## Valuation arithmetic
