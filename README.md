# Legal Due Diligence - Simulated Workpaper

GitHub Pages static package for an anonymized legal due diligence workpaper.

## Files

- `index.html` - portfolio page with inline PDF and Word preview tabs
- `docs/LDD_Workpaper_CN.pdf` - Chinese PDF
- `docs/LDD_Workpaper_CN.docx` - Chinese Word
- `docs/LDD_Workpaper_EN.pdf` - English PDF
- `docs/LDD_Workpaper_EN.docx` - English Word

## Deploy

Replace the contents of the existing `pevc-legal-portfolio` repository with the contents of this folder, commit, and push to the branch used by GitHub Pages.

PDF files are embedded directly by the browser. Word files are previewed through Microsoft Office Online Viewer after the site is publicly available on GitHub Pages.

## Disclaimer

All names, figures, document references and findings are fictional and anonymized. The materials do not relate to any real client or transaction and are not legal advice.
