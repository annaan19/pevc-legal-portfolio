# Project Aurora — Investor-Side Legal Due Diligence Portfolio

GitHub Pages-ready replacement package for:

`https://annaan19.github.io/pevc-legal-portfolio/`

## What is included

- `index.html` — bilingual portfolio landing page with methodology, red flags, workpaper extracts and embedded document preview.
- `docs/Project_Aurora_LDD_CN.pdf` — Chinese annotated LDD portfolio report.
- `docs/Project_Aurora_LDD_CN.docx` — Chinese editable Word version.
- `docs/Project_Aurora_LDD_EN.pdf` — English annotated LDD portfolio report.
- `docs/Project_Aurora_LDD_EN.docx` — English editable Word version.
- `assets/` — ownership and corporate-history visuals used inside the reports.
- `.nojekyll` — tells GitHub Pages to serve files as-is.

## Deploy / replace the existing site

1. Replace the current repository contents with the files in this package.
2. Commit and push to the branch used by GitHub Pages (typically `main`).
3. In **Settings → Pages**, keep the source as the repository root (or adjust if your repo uses `/docs`).
4. Visit `https://annaan19.github.io/pevc-legal-portfolio/` after the new commit is deployed.

## Document preview behavior

- **PDF** is shown directly inside the page using the browser's native PDF viewer.
- **Word** is embedded using Microsoft Office Online Viewer. This only works after the `.docx` files are publicly reachable at the GitHub Pages URL.
- The “Open in new tab” link provides a second online-view option.

## Portfolio status

This is a **fictional legal work sample**. It does not represent a client mandate, real target company, completed legal due diligence or legal advice. The diligence methodology is adapted from a user-provided LDD guide; the source guide itself is not republished.
