# PE/VC Legal Work Sample — GitHub Pages

这是一个静态求职作品集原型。

## 发布方式
1. 新建 GitHub repository，例如 `pevc-legal-work-sample`。
2. 将本目录中的所有文件上传到仓库根目录。
3. 在 Settings → Pages → Build and deployment 中选择 `Deploy from a branch`。
4. Branch 选择 `main`，目录选择 `/(root)`，保存。
5. GitHub 会生成公开访问链接。

## 后续替换
- `assets/PEVC_Legal_Work_Sample_v1.pdf`：替换为最终整合版工作样本 PDF。
- 首页中的“后续制作 / 最终版完成后开放”可在完成 Red Flag、Redline、IC Summary、英文摘要后改成链接。
